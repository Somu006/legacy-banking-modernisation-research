# Q and A

Questions the team has actually asked during preparation, answered and sourced.

Distinct from `05 - Risks and Judge Questions.md`, which is a pre-written list of
questions we *expect* a jury to ask. This folder is the running record of
questions that came up in real conversation — design choices someone wanted
justified, figures someone doubted, terms someone did not know.

**Why keep it:** any question a team member had to ask is a question a judge can
ask. Each entry here is a defence rehearsed once and written down, so nobody has
to reconstruct it under pressure in Kolkata.

**Convention.** One file per question, numbered in the order asked:
`NN - Short question.md`. Each file states the question, gives the short answer
first, then the evidence with a pointer into `01`–`08`. British spelling
throughout, matching the rest of the folder. If an answer rests on an assumption
rather than a source, say so in the file — the same rule the research uses.
